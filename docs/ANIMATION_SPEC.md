# 动画规格说明：LeetCode 309

## 1. 本题结构与焦点

| 项目 | 内容 |
| --- | --- |
| 主数据结构 | 价格数组 `[1,2,3,0,2]`，索引按 `price-i` 稳定标识 |
| 辅助结构 | 三状态动态规划：持股 `hold`、今日卖出 `sold`、休息 `rest` |
| 标量 | 天数、今日价格、三状态利润、最大非持股利润 |
| 焦点上限 | 每帧 1 个 `current`，最多 2 个 `compare` |
| 帧数 | 六帧：第 0–4 天状态转移及最终答案 |

## 2. 步骤规划

| step | operation | 焦点 | 状态变化 | 解说 | anchor |
|---|---|---|---|---|---|
| 0 | init | 第 0 天价格 | 初始化 hold=-1、sold=-∞、rest=0 | 首日买入成本及不可达卖出状态 | init |
| 1 | compare | 第 1 天价格 | 由前日状态计算三种状态 | 买入只允许从前日休息状态转移 | transition |
| 2 | compare | 第 2 天价格 | 卖出状态获得利润 | 今日卖出后次日处于冷冻期 | transition |
| 3 | compare | 第 3 天价格 | 价格为 0，更新持股利润 | 休息状态可以买入 | transition |
| 4 | compare | 第 4 天价格 | 更新末日卖出和休息状态 | 比较可行的最终非持股利润 | transition |
| 5 | done | 最终答案 | 最优状态标记 done | 返回 max(sold, rest)=3 | return |

节点使用固定坐标规则：价格节点 `x=150+220*i,y=170`；三状态位于同一天的固定泳道 `y=365/555/745`。ID 为 `price-i`、`hold-day`、`sold-day`、`rest-day`，跨帧复用。主视图以价格数组和同日状态快照解释冷冻期，箭头沿时间轴标注转移公式。

## 3. 运动语法、状态图例与教学层

**运动语法：** 统一使用模板 `features/animation/motion.ts` 的 `MOTION` token：入场 220ms、移动 360ms、退场 180ms、箭头 420ms；CSS 状态切换 240ms。跳步中断过渡并沿 keyed join 更新，退出元素通过 `fadeOutAndRemove` 清理。

**状态图例：** 固定 current/compare/visited/done 色板及图例；状态同时由徽标/描边表达。每帧包含操作徽标、独立解说、变量旁注、三项快照指标。

**稳定布局：** 价格节点使用 `x=150+220*i,y=170`，状态泳道固定 `y=365/555/745`；ID 在步骤间复用，禁止每帧随机重排。

**prefers-reduced-motion：** JS 过渡时长归零，CSS transition/animation 关闭，状态、解说、代码高亮和图例仍完整更新。

## 4. 辅助结构容器

本题不使用栈或队列，因此无辅助容器；可视数据是价格数组和同日三状态 DP 快照。容器验收不适用，模板通用 stack/queue 渲染与测试保留。

## 5. 箭头与标注规范

每条状态转移箭头带动作/公式文字；价格节点上方标注今日价格，解说解释冷冻期如何限制买入来源。箭头连接时间相邻状态节点并避开节点圆心，标注采用模板尺寸规则。

## 6. 空间预算与验收

顶部、输入、页签和控制栏按单行紧凑模板；画布优先。在 1920×1080、1366×768 验证空间预算、无纵向滚动及 SVG 占比。验收包含 1x/3x 播放、随机跳步、解法切换、reduced-motion、稳定 ID 与节点残留检查。
